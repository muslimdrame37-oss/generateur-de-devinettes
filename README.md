# Générateur de devinettes

Petit site qui permet d'afficher une devinette au hasard et afficher sa réponse à la demande. 

- Sur la page, vous avez un titre et un petit texte qui indique tout de suite à quoi sert la page. 
- Aucune devinette n'est affichée tant qu'on ne clique pas sur le bouton "Nouvelle devinette". 
- Le bouton "Voir la réponse" n'affiche de réponse qu'après avoir tiré une devinette, sinon un message indique qu'il faut d'abord en tirer une.
